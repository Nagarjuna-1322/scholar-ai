# **App Name**: ScholarAI

## Core Features:

- Profile Creation & Management: Users can create and manage their profiles, including education, income, and academic performance.
- AI-Powered Scholarship Recommendations: An AI tool analyzes user profiles and recommends relevant scholarships based on eligibility criteria.
- Scholarship Search & Filtering: Users can search and filter scholarships based on keywords, tags, and providers.
- Deadline Tracking: The app will display and sort available scholarships by their deadline to focus the user.
- Quick Chat AI Assistant: A rule-based AI tool answers user questions about scholarship eligibility and deadlines.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) for a trustworthy and intellectual feel.
- Background color: Light gray (#F0F0F0) to provide a clean and neutral backdrop.
- Accent color: Violet (#8F00FF) for highlighting important elements and calls to action.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy look.
- Body font: 'Inter' (sans-serif) for readability and a neutral feel.
- Code font: 'Source Code Pro' for code snippets.
- Use simple, outline-style icons to represent different scholarship categories and features.
- Employ a clean, card-based layout to display scholarships and recommendations.
- Subtle transitions and animations to provide feedback during interactions and improve user experience.
